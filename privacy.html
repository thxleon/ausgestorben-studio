Privacy Policy

Last updated: 26 October 2026

1. Who is responsible

Ausgestorben Studio is a private tool operated by the creator of the TikTok account @ausgestorbenodernicht (Germany).

2. What data is processed

When the operator connects their TikTok account, TikTok provides an access token and the account's open ID. These are used only to upload the operator's own videos to the operator's TikTok inbox via the Content Posting API (scope video.upload) and to check the upload status.

3. What is not processed

The tool does not collect data from other TikTok users, does not read followers, comments, messages or analytics, and does not use cookies or tracking on this website.

4. Storage

Access tokens are stored securely as encrypted secrets in the operator's private automation environment and are never shared with third parties. Tokens can be revoked at any time in the TikTok app (Settings → Security → Manage app permissions).

5. Hosting

This website is hosted on GitHub Pages. GitHub may process technical access data (e.g. IP address) as described in GitHub's privacy statement.

6. Your rights

Under the GDPR you have rights of access, rectification, erasure and objection. Since the tool only processes the operator's own account data, requests can be sent via TikTok: @ausgestorbenodernicht.
